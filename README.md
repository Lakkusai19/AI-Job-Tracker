# 🤖 AI Job Tracker

A Full Stack AI-powered Job Tracker built using React.js and Django REST Framework. This application helps users manage job applications, track application status, and generate professional AI-powered cover letters.

---

## 🚀 Features

- 🔐 User Authentication (JWT Login & Registration)
- 📊 Dashboard with Job Statistics
- 💼 Add, Edit & Delete Job Applications
- 📈 Interactive Charts
- 🤖 AI Cover Letter Generator
- 📄 Download Cover Letter as PDF
- 📋 Copy Cover Letter
- 🎨 Responsive Modern UI
- 🔒 Secure REST APIs

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/AI-Job-Tracker.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

---

## 🔑 Environment Variables

Create a `.env` file in the backend.

Example:

```env
GEMINI_API_KEY=YOUR_API_KEY
SECRET_KEY=YOUR_SECRET_KEY
DEBUG=True
```
